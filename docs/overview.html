design-styles

Design intelligence for AI coding agents. It reasons about the problem before choosing a look, draws on 64 catalogued styles as grammars rather than presets, and verifies every visual output by rendering it.

GitHub repository EVALUATION.md Gallery

What it is

A skill for Claude Code that behaves like a designer with formal training: it extracts principles from disciplines that already solved the hard problem (aerospace alerting, watch-dial legibility, architectural rhythm) and re-expresses them natively in the target medium. Copying a look is allowed only when the brief asks for that identity.

64-style catalogue

Each style is a grammar: visual DNA, construction rules, allowed variation, anti-patterns and tests. Composable, never a mood board.

Render-and-verify loop

Every SVG and page is parsed, rendered in headless Chrome at target and small sizes on light and dark, and inspected before it ships. No unverified claims.

Design systems aware

Detects an existing design-system skill or project tokens and obeys them as the token source; it can also generate a design-system skill for a project that has none.

How a job runs

Jobs run through a compiler model (the skill's Design Engineering Language): vague adjectives are rewritten into measurable rules, and machine-checkable things are machine-checked.

  1. Parse the brief. Medium, objective, audience, dimensions, constraints; an unparseable brief gets one focused question.
  2. Resolve tokens. Typography, spacing, colour and geometry bound to typed values before anything is generated.
  3. Generate. The artefact, in the target medium's native capabilities.
  4. Automated checks. Parse validity, contrast ratios, overflow, dangling references, rule violations.
  5. Visual evaluation. The rendered output judged for balance, hierarchy and style fidelity; neither pass substitutes for the other.
Sketch

One pass, one verification. For simple assets where standard competent practice is the right answer.

Studio

The full loop: make, verify, critique, decide, record, until two consecutive clean passes.

Flagship

Parallel exploration: several isolated directions rendered identically, collapsed to one by blind critique.

The crew

Eight installable agent personas (cp agents/*.md ~/.claude/agents/), each one Claude at one station, arguing from evidence rather than ego.

SCOUT
Brief

Turns the request into a contract: purpose, constraints, weighted success criteria.

RELIC
References

Pulls precedents and principles from the catalogue and from other disciplines.

MUSE
Direction

Designs one candidate direction, isolated from the other MUSEs to prevent contamination.

FORGE
Build

Constructs the artefact to measurable rules; rewrites vague instructions before following them.

ROAST
Critique

Judges rendered candidates blind, against the brief's criteria, and commits to a verdict.

RAMP
Accessibility

Holds the floor: measured contrast, meaning never by colour alone, reduced-motion respect.

PIXEL
Verification

Renders everything at target and small sizes, both themes, and reports what it actually saw.

PENNY
Business

Keeps cost honest: depth matched to stakes, no Flagship spend on a Sketch problem.

Mistakes feed LESSONS.md, an append-only ledger. A lesson that keeps recurring is promoted into the reference rules, so the same failure is not paid for twice.

Evidence, not vibes

The skill was measured with a pre-registered protocol: identical tasks given to fresh agents with and without the skill, judged blind by LLM judges with pre-recorded A/B keys, on a weighted 9-criterion rubric out of 100.

9/9
treatment wins in the n=3 replication of tasks 1, 3 and 8 (sign test p ≈ 0.004)
+8.5
mean score gain per 100 in the replication; +12.5 on diagrams, +9.7 on dashboards, +3.3 on advisory text
7/8
tasks won in round one (mean +5.8, rising to +7.1 after the one found defect was fixed and re-run)
+22%
token cost of the treatment condition; the gain is not free

Recorded verdict: partially effective, direction confirmed.

The pre-registered success threshold was a +10 mean across all tasks, and the overall mean fell short of it, so the skill does not claim more. Where it clearly pays is visual-geometry work: diagrams cleared the threshold on their own. The one regression found (an optically undersized icon glyph) became a rule, a rerun, and a confirmed win.

Activation and install

Opt-in (default)

The skill runs only when explicitly invoked with /design-styles. It never injects itself into unrelated work.

cp -r design-styles ~/.claude/skills/design-styles

Automatic mode

One command switches the frontmatter so Claude may invoke it on design tasks; opt-in switches back.

python3 tools/set-activation.py auto
