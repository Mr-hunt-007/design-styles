# Perception and Attention

How designs earn attention and stay understood. These are evidence-informed heuristics from perception psychology, not guarantees: their effects depend on context, culture, familiarity and the viewer's goals. Never present them as laws, and never let impact outrank comprehension. This module combines with any style: the style defines how the work looks, this engine defines how the work guides attention, the design loop defines how it improves.

## 1. Perceptual principles (the working set)

- **Von Restorff (isolation) effect**: the element that differs from its surroundings stands out. Give ONE element distinctive scale, colour, shape or position, and keep the field restrained; two heroes cancel each other.
- **Figure-ground separation**: elements compete to be foreground. Use contrast, scale, spacing, overlap and light to make one unmistakable focal point. Applies to almost every medium.
- **Gestalt grouping**: proximity, similarity, continuity, closure and common region decide what reads as a group before any text is read. Design the grouping deliberately; whitespace is a grouping operator, not leftover space.
- **Closure and implied form**: viewers complete interrupted shapes. Interrupted circles, implied outlines and carved negative space make logos and icons feel found rather than drawn.
- **Predictive surprise**: perception runs on expectation; a controlled break in an established rhythm attracts attention. Establish the pattern first, break it once, and make the break mean something.
- **Curiosity gaps**: an incomplete pattern or unanswered visual question invites inspection. The payoff must exist and arrive; never hide information the viewer needs to understand the message.
- **Processing fluency**: the main message must decode easily; put complexity in secondary layers. Familiar patterns decode fastest; novelty is spent where it pays.
- **Cognitive load**: working memory is small. Chunk related controls, cut unnecessary choices, reveal advanced detail progressively.
- **Adaptation and fatigue**: repeated effects become invisible or tiring (notification colours, looping motion). Test under realistic exposure, not a single glance.

## 2. Attention architecture

Give deliberate sequence to every composition: **Interrupt** (a distinctive focal point), **Orient** (clear reading order, what matters first), **Intrigue** (one meaningful contrast or discovery), **Resolve** (the message, insight or action that rewards the attention). This is a pattern, not a law: an operations dashboard needs immediate clarity over intrigue; a campaign poster can spend more on surprise. For each design, be able to name: the focal point, the reading order, the main message, the secondary discovery, the resolution.

## 3. Strategic interaction (when the work is interactive)

Borrow from decision theory only when real choices and consequences exist: meaningful alternatives with visible consequences, immediate and understandable feedback, progressive disclosure the user controls, reversibility. Points, badges and streaks are gamification, not strategy; add them only with a clear purpose. An interface teaches its rules by responding consistently.

## 4. The four attention loops (run inside the design loop)

When critiquing or refining (workflows/design-loop.md), check each loop separately:

1. **Perception**: does the intended focal point win the first glance? (Squint test, thumbnail render.)
2. **Comprehension**: can a first-time viewer state the main message without effort? (Say it aloud from the render alone.)
3. **Consistency**: does the output obey the style grammar and system tokens in force?
4. **Technical**: does the rendered artefact meet its measurable constraints? (The deterministic pass from design-engineering-language.md.)

An AI judgement of these is a useful screen, not proof of human attention or preference; where stakes justify it, test with representative viewers and measure task-relevant outcomes (time to message, correct interpretation, recall, completion).

## 5. Ethical constraints (hard floor)

No deceptive urgency, fabricated scarcity, covert manipulation, or deliberately confusing interfaces to force engagement. Never sacrifice comprehension or accessibility for impact. Attention is earned through relevance, craft and meaningful discovery, or it is not worth having.
