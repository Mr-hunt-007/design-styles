# Candidate A — The typographic specimen

**Direction:** the banner is itself a flawless piece of typesetting — `design-styles` set bold across the full 1152px measure on warm paper, so the type is the image and the craft is the claim.
**System:** one measure (64–1216) ruled top; grotesk stack (Helvetica Neue → Helvetica → Arial → Liberation Sans, mono for figures); two inks + one drafting red reserved for the annotation layer (baseline hairline, dimension line "1152"), which quietly demonstrates render-and-verify; tracked-caps meta carries only README facts, including the honest "blind-judged verdict: partially effective"; wordmark ink optically overshot (x=59, textLength=1162) so glyph edges, not advance widths, align to the measure.
**Excluded:** illustration, gradients, dark hero chrome, mock terminals, any logo/mascot — anything that would let decoration outrank the typesetting.
**Risk:** austerity — on a feed it must read as discipline, not emptiness; and the full-measure wordmark depends on `textLength`, so any renderer that ignores it must be caught at export (the PNG is the shipped surface).
**Verified:** XML parses; rendered via headless Chrome at 1280×640 and at 400px wide on white AND GitHub-dark surrounds; pixel-measured ink extents (wordmark 65–1215 vs rule 64–1215; all content inside the 64px safe margin; descenders end y≈561 < 576); name and both value-prop lines readable at 400px; contrast computed ≥4.5:1 for every text colour. Unverified: non-Chromium rasterisers and non-macOS font fallbacks (textLength pins the measure if fallback metrics drift).
